# Simple Interest Calculator

## Description
A Simple Interest Calculator is a tool used to calculate the interest on a principal amount over a specific period at a given rate.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time in Years

## Features
- Calculates simple interest.
- Calculates total amount.
- Easy to use.
- Provides quick results.

## Technologies Used
- HTML
- CSS
- JavaScript

## Output
The calculator displays:
- Simple Interest
- Total Amount
